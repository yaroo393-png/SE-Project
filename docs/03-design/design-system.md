# Design System & Screen Map — MedMind

## 1. Tokens (สี ฟอนต์ ระยะ) — ปุ่ม "กินแล้ว" เขียว / "ยังไม่กิน" แดง

งาน FR-02 ของ Rossatorn Sangkaew / IDK-SleepyBro อ้างอิง [MedMind Copy หน้า 14:8](https://www.figma.com/design/QApLysrw0Cin0OTNZpd0C0?node-id=14-8): ตั้งเวลามื้อ `2018:7037`, ร่างยา `2018:7438`, ตั้งเวลา/ดูเวลาเตือน `2010:6208`, แก้ยา `2010:6116` · ต้นแบบอ้างอิงเก็บที่ [`prototype/figma-IDK-SleepyBro/`](../../prototype/figma-IDK-SleepyBro/README.md) และฟีเจอร์ที่บันทึกข้อมูลจริงอยู่ใน `prototype/caregiver.html`

## 2. Components

| Component | พฤติกรรมและจุดเชื่อม |
|---|---|
| ฟอร์มตั้งเวลามื้อ | ช่องเช้า/กลางวัน/เย็น/เข้านอน เป็น `HH:MM`; แสดงครั้งแรกเมื่อ `readMealTimes().isDefault`; บันทึกผ่าน `MedMind.store.saveMealTimes()` |
| ฟอร์มยา | ชื่อยา จำนวนเม็ดต่อครั้ง เวลากินตามฉลาก มื้ออาหาร ข้อควรระวัง และข้อห้ามใช้; ชื่อช่องเดิม `name`, `dose`, `time`, `instruction` คงไว้ให้ระบบสแกน |
| ตัวเลือกมื้อ | เลือกเช้า/กลางวัน/เย็นได้หลายมื้อ; เลือกก่อนนอนแล้วซ่อนตัวเลือกมื้ออาหาร; ช่องนาทีแสดงเฉพาะก่อนอาหาร |
| เวลาเตือนตัวอย่าง | แสดงผลจาก `medication.preview()` ที่เรียก `reminder.reminderTime()` ของทีม เช่น ก่อนอาหารเช้า 30 นาที → 06:30; การดูตัวอย่างไม่เขียนข้อมูล |
| ช่องต้องตรวจ | ใช้ class `needs-review` เดิมร่วมกับข้อความ “กรุณาตรวจสอบ”; ถ้าช่องบังคับไม่ครบ ปุ่มบันทึกใช้ไม่ได้ |
| การ์ดยา | ชื่อและขนาดยา เวลาเตือนทุกมื้อ ข้อควรระวัง/ข้อห้ามใช้ถ้ามี; แก้หรือลบโดยรหัสรายการ ไม่ใช้ชื่อยาเป็นตัวระบุ |
| กล่องสนทนา | เลื่อนได้เมื่อเนื้อหายาว; ช่องกรอกและปุ่มบันทึกเข้าถึงได้บนจอมือถือ; ปิด/ยกเลิกไม่เรียกบันทึกยา |

## 3. Screen Map: หน้าจอ ↔ FR (ทุกหน้ากำกับ "Covers: FR-x")
หน้าที่ต้องมีจาก requirement: Senior — เริ่มต้น/QR (FR-01), หน้าเตือน (FR-03), **หน้าแรก** (FR-04, BR-15) · Caregiver — จับคู่ (FR-01), สแกน/ร่าง/ตั้งเวลามื้อ (FR-02), แจ้งเตือน + หน้าสถานะรายวัน (FR-05)

| หน้าจอ/ส่วน | Path ที่เปิดจริง | Covers / เจ้าของงาน |
|---|---|---|
| เลือกบทบาท / แสดงสองบทบาท | `prototype/role.html` / `prototype/demo.html` | ทางเข้า FR-01; YAR OO (ย้าย path ตาม #46) |
| ผู้สูงอายุ: หน้าแรก/เมนู/จับคู่ | `prototype/index.html` | FR-01, FR-03, FR-04 ตามป้ายของหน้าเดิม; โครงหน้า Rossatorn, logic ฟีเจอร์ตามเจ้าของใน README |
| ผู้ดูแล: ยาและตารางยา | `prototype/caregiver.html` → เมนูยา | FR-02; Rossatorn |
| ตั้งเวลามื้อครั้งแรก/แก้เวลามื้อ | หน้าเดียวกัน → เวลามื้อ | FR-02 ✓6, ✓8, ✓9 · BR-05–06; Rossatorn |
| เพิ่ม/แก้ร่างยาและเวลาเตือน | หน้าเดียวกัน → เพิ่มยา/แก้ยา | FR-02 ✓2, ✗3, ✗7, ✗10 · NFR-06; Rossatorn |
| ถ่ายภาพ/ฉลากตัวอย่าง | ในฟอร์มยา `#medicine-form` | FR-02 ✓1, ✗3–5, ✗10; สแกน YAR OO + adapter ฟอร์ม Rossatorn |
| ผู้ดูแล: ภาพรวม/แจ้งเตือน | `prototype/caregiver.html` → เมนูเดิม | FR-05; งานของเพื่อน #50 ไม่เปลี่ยน logic ใน #48 |

## 4. Error / Empty states

| สถานะ | ข้อความ/การตอบสนอง |
|---|---|
| ยังไม่มียา | แสดงหน้าว่างพร้อมปุ่มเพิ่มยา; ไม่สร้างยาเริ่มต้นลง storage แทนผู้ดูแล |
| ค้นหาไม่พบ | แสดงว่าไม่พบรายการ ให้เปลี่ยนคำค้น |
| ช่องบังคับว่าง / จำนวนเม็ดไม่เป็นจำนวนเต็ม | ขึ้นกรอบและคำอธิบาย “กรุณาตรวจสอบ”; ไม่บันทึก |
| ก่อนอาหารไม่มีนาที | ช่องนาทีว่างพร้อมคำเตือน; ไม่เดา 15/30 นาทีและไม่บันทึก |
| อ่านฉลากไม่ได้ | ใช้สถานะจากระบบสแกนเดิมและให้กรอกเอง; ไม่สร้างร่างที่เดาค่า |
| ยาเมื่อมีอาการ/ยาน้ำ/ยาครึ่งเม็ด | แจ้งไม่รองรับชนิดนั้นและไม่สร้างตาราง (BR-07) |
| พื้นที่จัดเก็บใช้ไม่ได้ | แจ้งบันทึก/ลบไม่สำเร็จ คงหน้าร่างให้ตรวจและลองใหม่; ไม่แสดงว่าสำเร็จ |
| ยกเลิก | ปิดร่างและทิ้งข้อมูลที่ยังไม่ยืนยัน; รายการยาเดิมไม่เปลี่ยน |

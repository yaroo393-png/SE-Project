# Decision Log — Requirements (5 FR)

สถานะ: **ร่าง** · อาจารย์กำหนด MVP = 5 FR · แหล่งข้อมูล: เอกสารปัญหาฉบับใหม่ + การตัดสินใจของทีม (ไม่ใช้ M1/M2 เดิม) · ตัวเลขเวลาเป็นเป้าของทีม ต้องยืนยันกับผู้ใช้จริง

## 0. ปัญหา

**ปัญหา:** ผู้สูงอายุที่ต้องรับประทานยาเป็นประจำอาจลืมกินยา กินไม่ตรงเวลา หรือจำไม่ได้ว่ากินแล้วหรือยัง ขณะที่ลูกหลานต้องออกไปทำงานและไม่สามารถติดตามได้ตลอดวัน วิธีปัจจุบัน เช่น นาฬิกาปลุก กล่องยา การโทรถาม และการส่ง LINE ยังไม่สามารถยืนยันและสรุปสถานะการกินยาให้ผู้ดูแลทราบโดยอัตโนมัติได้

**ข้อจำกัดของวิธีปัจจุบัน**
- นาฬิกาปลุกแจ้งเวลา แต่ไม่ทราบว่ากินยาแล้วหรือยัง
- กล่องยาไม่สามารถส่งสถานะให้ผู้ดูแลได้
- การโทรหรือส่ง LINE ต้องใช้คนตรวจสอบทุกมื้อ
- ไม่มีข้อมูลสถานะการกินยาที่รวบรวมไว้ในที่เดียว

**สาเหตุหลัก:** การติดตามการกินยายังพึ่งพาการสื่อสารด้วยตนเอง และไม่มีการเชื่อมโยงตารางยา การแจ้งเตือน และสถานะการยืนยันระหว่างผู้สูงอายุกับผู้ดูแลอย่างเป็นระบบ (5 Whys อยู่ใน Charter — เป็นสมมติฐานเบื้องต้น)

| Pain / ความต้องการ | FR | ที่มา |
|---|---|---|
| ลืมกินยา / กินไม่ตรงเวลา / จำไม่ได้ว่ากินแล้ว | FR-03, FR-04 | ปัญหา · ผู้ให้สัมภาษณ์ 1 |
| ผู้ดูแลไม่อยู่ด้วย ต้องโทร/ส่ง LINE ถามทุกมื้อ | FR-01, FR-05 | ปัญหา · ผู้ให้สัมภาษณ์ 2 |
| ไม่มีข้อมูลสถานะรวบรวมไว้ในที่เดียว | FR-05 (หน้าสถานะรายวัน) | ข้อจำกัดวิธีปัจจุบัน |
| ผู้ดูแลอยากถ่ายรูปฉลากให้ช่วยกรอก / ผู้สูงอายุอยากให้ลูกตั้งค่า | FR-02 | ผู้ให้สัมภาษณ์ 2, 3 |
| ผู้สูงอายุไม่สะดวกสมัครบัญชี | FR-01 | ผู้ให้สัมภาษณ์ 3 |

## 1. FR (5 ข้อ — Must ทั้งหมด)

| FR | ชื่อ | สิ่งที่รวมอยู่ |
|---|---|---|
| FR-01 | จับคู่ Senior–Caregiver | QR Code หรือรหัสเชิญ; Senior ไม่ต้องสมัครบัญชี แต่ต้องกดยินยอมก่อนเชื่อมต่อ |
| FR-02 | สแกนฉลากยาและสร้างข้อมูลยา | สแกน → ร่าง → Caregiver ตรวจ/แก้ → บันทึก; กรอกเองได้ถ้าสแกนไม่ได้; ตั้งเวลามื้ออาหารครั้งแรก |
| FR-03 | แจ้งเตือนเมื่อถึงมื้อยา (หัวใจ MVP) | เตือนที่ T, แจ้งซ้ำ T+5, T+10; แสดงยาทั้งมื้อในหน้าเดียว |
| FR-04 | ยืนยันการกินยาทั้งมื้อ | ปุ่ม "กินแล้ว" 1 แตะ = ทั้งมื้อ; ปุ่ม "ยังไม่กิน" (เลื่อนไปเตือนรอบถัดไป); บันทึกสถานะ + เวลา; เป็นการรายงานด้วยตนเอง |
| FR-05 | แจ้งเตือน Caregiver + สถานะรายวัน | ถึง T+15 ยังไม่ยืนยัน → แจ้ง Caregiver "ยังไม่ยืนยันการกินยา" (หรือทันทีถ้ากด "ยังไม่กิน" ในรอบสุดท้าย; แจ้ง 1 ครั้งต่อมื้อ); Caregiver ดูสถานะทุกมื้อของวันได้ในหน้าเดียว |

## 3. Timeline การเตือน

```
T      เตือนครั้งแรก      [กินแล้ว] [ยังไม่กิน]
T+5    แจ้งซ้ำครั้งที่ 1   (ถ้ายังไม่ยืนยัน)
T+10   แจ้งซ้ำครั้งที่ 2   (รอบสุดท้าย; กด "ยังไม่กิน" = แจ้ง Caregiver ทันที)
T+15   ยังไม่ยืนยัน → แจ้ง Caregiver "ยังไม่ยืนยันการกินยา" (ถ้ายังไม่ได้แจ้งที่ T+10)
```

## 4. Acceptance Criteria (สรุป)

> ฉบับหลักอยู่ที่ `spec.md` §3 (Given/When/Then) — ถ้าแก้ AC ให้แก้ที่ spec ก่อน แล้วอัปเดตสรุปนี้ให้ตรง

### FR-01 จับคู่
1. Senior เปิดแอปครั้งแรก → เห็น QR + รหัสเชิญ ไม่ต้องสมัคร/พิมพ์
2. Senior ยังไม่กดยินยอม → จับคู่ไม่ได้ และแจ้งว่ารอการยินยอม
3. Caregiver สแกน/ใส่รหัสที่ถูกต้อง → ทั้งสองเครื่องแสดงว่าเชื่อมต่อแล้ว
4. รหัสไม่ถูกต้อง / หมดอายุ (ตาม BR-01) → ปฏิเสธพร้อมข้อความชัดเจน ไม่เชื่อมต่อ

### FR-02 สแกนฉลาก
1. รูปชัด → แสดงร่าง (ชื่อยา, จำนวนเม็ดต่อครั้ง, มื้อ/เวลา, ข้อควรระวัง, ข้อห้ามใช้) ยังไม่บันทึก
2. Caregiver แก้ช่อง → บันทึก → ค่าที่บันทึก = ค่าที่แก้ ไม่ใช่ค่าที่ OCR อ่าน
3. ช่องที่อ่านไม่ได้ → ว่าง + "กรุณาตรวจสอบ"; บันทึกไม่ได้จนช่องบังคับครบ
4. ฉลากยาเมื่อมีอาการ → แจ้ง "ระบบยังไม่รองรับ" ไม่สร้างตาราง
5. สแกนล้มเหลว → เปิดฟอร์มว่างให้กรอกเอง
6. เพิ่มยาครั้งแรก → Caregiver ตั้งเวลามื้ออาหาร → เวลาเตือนคำนวณจากเวลามื้อ
7. กดยกเลิก → ไม่บันทึกอะไร

### FR-03 แจ้งเตือน
1. มื้อ 08:00 มียา 2 ตัว → 08:00 แสดงเตือน ยาทั้ง 2 ตัวในหน้าเดียว + ปุ่ม "กินแล้ว" / "ยังไม่กิน"
2. ยังไม่ยืนยัน → 08:05 แจ้งซ้ำ, 08:10 แจ้งซ้ำ
3. ยืนยันแล้ว → ไม่แจ้งซ้ำอีก

### FR-04 ยืนยัน
1. กด "กินแล้ว" 08:03 → สถานะ "กินแล้ว" + 08:03, หยุดเตือน
2. กด "กินแล้ว" ซ้ำ → ไม่บันทึกซ้ำ
3. กด "ยังไม่กิน" ที่ 08:00 → เตือนอีกครั้ง 08:05
4. กด "ยังไม่กิน" ที่รอบ 08:10 → แจ้ง Caregiver ทันที

### FR-05 แจ้ง Caregiver + สถานะรายวัน
1. ยืนยัน 08:12 → ไม่แจ้ง Caregiver
2. ไม่ยืนยันจนถึง 08:15 → แจ้ง Caregiver "ยังไม่ยืนยันการกินยา"
3. Caregiver เปิดหน้าสถานะ → เห็นทุกมื้อของวันพร้อมสถานะและเวลา
4. ยังไม่มีมื้อใดในวัน → แสดง "ยังไม่มีมื้อยาวันนี้" (empty state)
5. กด "ยังไม่กิน" ในรอบ 08:10 (แจ้ง Caregiver ไปแล้ว) → ถึง 08:15 ไม่แจ้งซ้ำ

# วัดผล NFR-08 — เวลาอ่านฉลากจริง 20 ใบ

> Issue #51 · ผู้วัด: YAR OO + Suchitra · ผลนี้ใช้ใน Final Report §6
> **NFR-08:** ร่างที่อ่านจากรูปฉลากแสดงภายใน **10 วินาที** หลังส่งรูป ใน **≥ 18 จาก 20 ฉลาก** (90%)

## วิธีวัด

1. เปิด prototype ในมือถือ: <https://yaroo393-png.github.io/SE-Project/> → ผู้ดูแล → ยา → เพิ่มรายการยา
2. **สแกนใบแรก 1 ครั้งก่อนเริ่มนับ** (โหลดตัวอ่าน ~8 MB ครั้งแรก — ไม่นับใบนี้) · ใช้ Wi-Fi
3. ถ่ายฉลากทีละใบ จดเวลาจากข้อความ **"ร่างจากการอ่านรูป (X วินาที)"** ที่ขึ้นบนจอ
4. เทียบแต่ละช่องกับฉลากจริง: ✓ ถูก · ✗ ผิด (เติมค่าผิด) · ว่าง (ระบบไม่เติม ขึ้นกรอบแดง)
5. **ห้ามเก็บรูป / ชื่อผู้ป่วย / HN** — จดแค่ชื่อยาและผล (NFR-09)

# Prototype — MedMind

Clickable prototype (HTML/CSS/JS) เปิดในเบราว์เซอร์ **ไม่ต้องมี server / ฐานข้อมูล** — ข้อมูลอยู่ใน `localStorage` ของเบราว์เซอร์

> สถานะ: **บางส่วน** — ยังไม่ครบ AC ของ FR-01..05 และหน้าเว็บยังไม่ได้เรียกใช้ `js/logic/reminder.js` / `confirm.js` (#49, #50) · สแกนฉลาก (FR-02) ใช้ได้แล้วในหน้าผู้ดูแล

## วิธีเปิด
ออนไลน์ (GitHub Pages, เปิดในมือถือได้): <https://yaroo393-png.github.io/SE-Project/> · หรือเปิดไฟล์ในเครื่องตามขั้นตอนด้านล่าง

1. เปิด [`MedMind-Responsive/role.html`](MedMind-Responsive/role.html) (หรือ `index.html` ชั้นนอกสุดของ repo) → **เลือกบทบาทก่อนเข้าแอป**
   - **ผู้สูงอายุ (Senior)** → `index.html` · **ลูกหลาน / ผู้ดูแล (Caregiver)** → `caregiver.html` — เปิด 2 หน้านี้ตรง ๆ ก่อนเลือกบทบาทจะถูกพากลับหน้าเลือกบทบาท
   - บทบาทจำแยกต่อแท็บ: เปิด 2 แท็บในเบราว์เซอร์เดียวกัน เลือกคนละบทบาท = จำลองมือถือ 2 เครื่อง · หรือ [`demo.html`](MedMind-Responsive/demo.html) ดูทั้ง 2 บทบาทในจอเดียว
2. เปลี่ยนบทบาท: ปุ่มลูกศรสลับที่แถบด้านบนของแอป
3. สแกนฉลาก (FR-02): หน้าผู้ดูแล → **ยา** → **เพิ่มรายการยา** → ถ่ายภาพ/เลือกรูปฉลาก หรือเลือก **ฉลากตัวอย่าง**
   - ระบบอ่านรูปในเบราว์เซอร์แล้วเติมชื่อยา ขนาด เวลา และคำแนะนำให้ — **ยังไม่บันทึกจนผู้ดูแลตรวจแล้วกดบันทึกเอง**
   - ช่องที่อ่านไม่ได้จะว่างและขึ้นกรอบแดง "กรุณาตรวจสอบ" (ระบบไม่เดา) · ยาเมื่อมีอาการ / ยาน้ำ / ครึ่งเม็ด บันทึกไม่ได้
   - ชื่อยาที่ OCR อ่านแตก/เพี้ยน ("AMLODIP INE") ระบบแก้ให้ตรงรายการยาที่ใช้บ่อยใน `labelParser.js` แต่ยังขึ้นกรอบแดงให้ตรวจ · ก่อนอ่าน `scanner.js` ลบเงา/แสงสะท้อนของรูปก่อน
   - อ่านตารางสีข้างฉลาก ("เช้า 2 เม็ด / เที่ยง - / เย็น 1 เม็ด / ก่อนนอน -") ได้: แยกมื้อและจำนวนเม็ดรายมื้อ แต่ชนิด ก่อน/หลังอาหาร ต้องมาจากข้อความบนฉลาก (BR-06) · ตารางอ่านไม่ครบ → มื้อว่างให้เลือกเอง
   - **ดูข้อความที่อ่านได้**: กล่องใต้ผลสแกน แสดงข้อความที่ระบบอ่านจากรูป (ซ่อนบรรทัดผู้ป่วย/HN แล้ว) ใช้เทียบว่าช่องไหนว่างเพราะอ่านไม่ออก · ไม่ถูกบันทึก ล้างทิ้งเมื่อปิดฟอร์ม
   - ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลดตัวอ่าน (Tesseract.js ~4 MB) · ฉลากตัวอย่างใช้ได้แม้ไม่มีเน็ต — ใช้ demo ทุกกรณีของ AC
   - รูปฉลากไม่ถูกส่งออกนอกเครื่อง และไม่ถูกเก็บ (NFR-09)

## โครงไฟล์
| โฟลเดอร์ | คืออะไร | ผู้รับผิดชอบ |
|---|---|---|
| `MedMind-Responsive/` | หน้าเว็บ demo: `index.html`, `caregiver.html`, `styles.css`, `app.js`, `flows.js` | Rossatorn |
| `MedMind-Responsive/role.html`, `demo.html`, `js/core/role.js`, `js/features/roleSelect.js`, `css/role.css` | หน้าเลือกบทบาท (ทางเข้าเดียวของแอป) + ดูทั้ง 2 บทบาท · `role.js` ใส่ไว้บนสุดของ `<head>` ในหน้าแอปเพื่อกันเข้าก่อนเลือกบทบาท | YAR OO |
| `js/core/store.js` | ชื่อ key ใน localStorage + เวลามื้ออาหาร — ทุกฟีเจอร์ใช้ข้อมูลผ่านไฟล์นี้ | YAR OO (PM) |
| `js/logic/` | ตรรกะล้วน ไม่แตะหน้าจอ มีเทสต์ทุกไฟล์: `reminder.js` (FR-03, BR-06, BR-08) · `confirm.js` (FR-04, FR-05) · `labelParser.js` (FR-02: ข้อความฉลาก → ร่าง) · `labelForm.js` (FR-02: ร่าง → ฟอร์ม, BR-06) | Nichanan · YAR OO |
| `js/services/scanner.js` | อ่านตัวหนังสือจากรูปในเบราว์เซอร์ (Tesseract.js ไทย + อังกฤษ) | YAR OO |
| `js/features/scan.js`, `css/scan.css` | สแกนฉลากในฟอร์มเพิ่มยาของหน้าผู้ดูแล | YAR OO |
| `tests/` | automated test ของ `js/logic/` และ `js/core/` | เจ้าของแต่ละไฟล์ |

ลำดับโหลดในหน้า HTML: `js/logic/` → `js/core/` → `js/services/` → `js/features/` (ในหน้าผู้ดูแลต่อจาก `flows.js` และ `app.js`)

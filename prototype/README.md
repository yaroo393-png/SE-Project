# Prototype — MedMind

Clickable prototype (HTML/CSS/JS) เปิดในเบราว์เซอร์ **ไม่ต้องมี server / ฐานข้อมูล** — ข้อมูลอยู่ใน `localStorage` ของเบราว์เซอร์

> สถานะ: **บางส่วน** — ยังไม่ครบ AC ของ FR-01..05 และหน้าเว็บยังไม่ได้เรียกใช้ `js/logic/reminder.js` / `confirm.js` (#49, #50) · สแกนฉลาก (FR-02) ใช้ได้แล้วในหน้าผู้ดูแล

## วิธีเปิด
ออนไลน์ (GitHub Pages, เปิดในมือถือได้): <https://yaroo393-png.github.io/SE-Project/> · หรือเปิดไฟล์ในเครื่องตามขั้นตอนด้านล่าง

1. เปิด [`role.html`](role.html) (หรือ `index.html` ชั้นนอกสุดของ repo) → **เลือกบทบาทก่อนเข้าแอป**
   - **ผู้สูงอายุ (Senior)** → `index.html` · **ลูกหลาน / ผู้ดูแล (Caregiver)** → `caregiver.html` — เปิด 2 หน้านี้ตรง ๆ ก่อนเลือกบทบาทจะถูกพากลับหน้าเลือกบทบาท
   - บทบาทจำแยกต่อแท็บ: เปิด 2 แท็บในเบราว์เซอร์เดียวกัน เลือกคนละบทบาท = จำลองมือถือ 2 เครื่อง · หรือ [`demo.html`](demo.html) ดูทั้ง 2 บทบาทในจอเดียว
2. เปลี่ยนบทบาท: ปุ่มลูกศรสลับที่แถบด้านบนของแอป
3. สแกนฉลาก (FR-02): หน้าผู้ดูแล → **ยา** → **เพิ่มรายการยา** → ถ่ายภาพ/เลือกรูปฉลาก หรือเลือก **ฉลากตัวอย่าง**
   - ระบบอ่านรูปในเบราว์เซอร์แล้วเติมชื่อยา ขนาด เวลา และคำแนะนำให้ — **ยังไม่บันทึกจนผู้ดูแลตรวจแล้วกดบันทึกเอง**
   - ช่องที่อ่านไม่ได้จะว่างและขึ้นกรอบแดง "กรุณาตรวจสอบ" (ระบบไม่เดา) · ยาเมื่อมีอาการ / ยาน้ำ / ครึ่งเม็ด บันทึกไม่ได้
   - ชื่อยาที่ OCR อ่านแตก/เพี้ยน ("AMLODIP INE") ระบบแก้ให้ตรงรายการยาที่ใช้บ่อยใน `labelParser.js` แต่ยังขึ้นกรอบแดงให้ตรวจ · ก่อนอ่าน `scanner.js` ลบเงา/แสงสะท้อนของรูปก่อน
   - อ่านตารางสีข้างฉลาก ("เช้า 2 เม็ด / เที่ยง - / เย็น 1 เม็ด / ก่อนนอน -") ได้: แยกมื้อและจำนวนเม็ดรายมื้อ แต่ชนิด ก่อน/หลังอาหาร ต้องมาจากข้อความบนฉลาก (BR-06) · ตารางอ่านไม่ครบ → มื้อว่างให้เลือกเอง
   - ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลดตัวอ่าน (Tesseract.js ~4 MB) · ฉลากตัวอย่างใช้ได้แม้ไม่มีเน็ต — ใช้ demo ทุกกรณีของ AC
   - รูปฉลากไม่ถูกส่งออกนอกเครื่อง และไม่ถูกเก็บ (NFR-09)
4. จัดการยา (FR-02, #48): ตั้งเวลามื้อครั้งแรก → ตรวจ/แก้ร่าง → เลือกก่อน/หลังอาหารหรือก่อนนอน → เลือกมื้อได้หลายมื้อ → ตรวจเวลาเตือน → บันทึก · ก่อนอาหารต้องใส่นาทีตามฉลาก
   - ข้อควรระวัง/ข้อห้ามใช้กรอกเมื่อฉลากมี (BR-05) · การยกเลิกหน้าร่างไม่บันทึกยา
   - คู่มือโค้ดและ demo: [FR02-IDK-SleepyBro.md](FR02-IDK-SleepyBro.md) · [ต้นแบบออกแบบ Figma แยก](figma-IDK-SleepyBro/index.html) เป็นงานออกแบบอ้างอิง ไม่ใช่หน้าบันทึกข้อมูลของทีม

## สัญญาข้อมูล FR-02 ที่ยังใช้ร่วมกับหน้าเดิม

`store.js` และชื่อ key เดิมไม่เปลี่ยน: รายการยาเก็บผ่าน `MedMind.store.KEYS.medicines` หนึ่งแถวต่อมื้อ คง `id`, `name`, `dose`, `time`, `instruction` และเพิ่ม `medicationId` ผูกมื้อของยาเดียวกัน, `pills`, `timing`, `caution`, `contraindication` เพื่อเก็บคำสั่งตามฉลากครบ การแก้/ลบใช้ id หรือ `legacyIndex` ที่ตรวจแล้วสำหรับรายการเก่าที่ไม่มี id ไม่ใช้ชื่อยาเป็นตัวระบุ

`medication.resolveTimes()` คำนวณเวลาแสดงผลจาก `timing` และเวลามื้อปัจจุบัน โดยไม่เขียนแถวเดิมอัตโนมัติ การเปลี่ยนเวลามื้อจึงแสดงเวลาเตือนใหม่ได้ และรายการ schema เก่าที่ยังไม่มี `timing` คงใช้เวลาที่บันทึกไว้ จุดเชื่อมฟอร์มสแกนยังรักษาชื่อ `name`, `dose`, `time`, `instruction`; `scan.js` / `labelForm.js` ของเพื่อนคงเนื้อหาเดิม

เมื่อ storage ยังไม่มีรายการยา จะแสดงหน้าว่างและปุ่มเพิ่มยา ไม่สร้างหรือบันทึกยาตัวอย่างแทนผู้ดูแล

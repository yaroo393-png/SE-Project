## เปิดตรวจงาน

1. ดาวน์โหลด repo แล้วเปิด [index.html](index.html) ในเบราว์เซอร์ ไม่ต้องติดตั้งหรือ build; หน้าแสดงโค้ดของ GitHub ไม่รัน HTML
2. ใช้แถบตรวจงานด้านบนเลือกหน้าจอ ภาษาไทย/English และธีมสว่าง/มืด ใช้แถบเดโมสลับบทบาทหรือ Reset
3. เปิดชุดหน้าจอด้วย `index.html?atlas=1&page=Onboarding` โดยเปลี่ยนชื่อหน้าเป็น `ผู้สูงอายุ`, `ผู้ดูแล`, `Desktop`, `Dark Mode`, `Design System` หรือ `Prototype`

มี 26 หน้าหลักใน 208 รูปแบบ และสถานะเพิ่มเติม 512 รูปแบบ รวม 720 รูปแบบหน้าจอในต้นแบบ ฟอนต์ Sarabun ไอคอน และมาสคอตอยู่ใน HTML แล้ว ไม่มีไฟล์ภาพจาก URL ชั่วคราวของ Figma

## ขอบเขตและสถานะ

- เป็นงานออกแบบเพื่อให้ทีมรีวิว หน้าจอครอบคลุมจับคู่ผู้ดูแล จัดการยา การเตือน ยืนยันมื้อยา และดูสถานะ ตาม FR-01–05
- QR/OCR การไหลของเวลา และการส่งสถานะในต้นแบบเป็นการจำลอง ไม่ใช่การเชื่อมต่อระบบของทีม ข้อมูลยาตัวอย่างเป็นข้อมูลสมมติ
- HTML นี้เป็นต้นฉบับงานออกแบบที่จัดทำก่อนนำเข้า Figma และเชื่อมกับ MedMind Copy ไม่ใช่ไฟล์ส่งออก native ล่าสุดจาก Figma การสร้าง Variables, Components และ Prototype ใน Figma ยังไม่ถือว่าตรวจเสร็จจากการอัปครั้งนี้
- งานใหม่อยู่ในโฟลเดอร์เฉพาะนี้ และยังไม่ต่อเข้าหน้าหรือ logic ของเพื่อน ไฟล์เก่าที่หน้าของเพื่อนเรียกใช้ยังคงไว้ ดูเหตุผลใน [คู่มือโฟลเดอร์แม่](../README.md)

หมายเหตุหลังจัดโครง #46: ต้นฉบับ `index.html` มี self-link สองตำแหน่งอ้างชื่อ `MedMind-Prototype.html` ซึ่งไม่มีใน repo และคงไว้ตามต้นฉบับเพื่อรักษา SHA-256 ใน `SOURCE.json` ให้เปิดต้นแบบด้วย [index.html](index.html) หรือ query ในหัวข้อ “เปิดตรวจงาน” แทน หน้าฟีเจอร์ทีมที่บันทึกข้อมูลจริงเปิดผ่าน [role.html](../role.html) ดูบันทึกการจัดโครงรอบก่อนใน [LEGACY-README.md](LEGACY-README.md)
